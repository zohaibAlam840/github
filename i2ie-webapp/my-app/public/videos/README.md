# Manual videos

Generated by `tools/demo` — see that folder's README.

    cd tools/demo
    npm install
    npx playwright install chromium
    npm run record

Then copy `tools/demo/out/*.webm` into this folder.

They are **not** committed: eleven screen recordings are ~40 MB, which does
not belong in a git repository, and they are regenerated from the dashboard
itself whenever the UI changes. Deliver them alongside the code.

The manual degrades honestly without them — each chapter still shows its
written steps, and the player says the video is not installed rather than
showing a dead black rectangle.
